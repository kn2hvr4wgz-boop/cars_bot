# cars_bot — отчёты водителей в Telegram

Водитель отмечает в боте старт/стоп смены, пробег, платные дороги, парковки и топливо
с фото чеков. Бот сам пересчитывает всё в деньги по условиям проекта, а администратор
принимает отчёты и одной кнопкой выгружает Excel по контрагенту с итогами и чеками.

## Как это работает

**Администратор (директор / транспортный координатор)**
1. `⚙️ Админка` → `➕ Новый проект`: название и условия — ставка за смену,
   длина смены, переработка ₽/ч, сколько км включено в смену и цена км сверх лимита.
2. Бот выдаёт ссылку-приглашение — её пересылают водителям.
3. У каждого водителя можно задать персональные условия (например, у минивэна ставка выше),
   они перекрывают условия проекта.
4. Отчёты приходят на проверку: `✅ Принять`, `↩️ Вернуть` (с причиной — водитель увидит и
   поправит), `🧾 Чеки`.
5. `📤 Выгрузка в Excel`: период (неделя / месяц / свои даты) → все контрагенты или один.
   Приходит архив: Excel + папка `Чеки/`, ссылки в Excel открывают фото чеков.

**Водитель**
- утром `▶️ Начать смену` (+ одометр, можно пропустить);
- в течение дня `🛣 Платная дорога`, `🅿️ Парковка`, `⛽ Топливо`, `🧾 Другой расход` —
  сумма и фото чека;
- вечером `⏹ Закончить смену` → пробег → проверить карточку → `✅ Отправить на проверку`;
- забыл отметиться — `📝 Смена задним числом`; время, дату и пробег можно поправить в карточке.

## Как считается

| Что | Формула |
|---|---|
| Смена | ставка за смену |
| Переработка | (часы − длина смены), округление вверх до шага (по умолчанию 60 мин) × ₽/ч |
| Км | (пробег − включённые км) × ₽/км; пробег = одометр конец − начало или введённое число |
| Расходы | суммы по чекам 1:1 |
| Итого | всё вместе |

Смена через полночь считается правильно (конец 02:00 → следующий день).
Расчёт всегда идёт по **текущим** условиям: исправили ставку — выгрузка пересчитается.

## Что в Excel

- **Сводка** — по каждому контрагенту: водителей, смен, переработка, км сверх,
  суммы по статьям и ИТОГО.
- **Лист на контрагента** — смена построчно: дата, водитель, авто, время, часы,
  переработка, пробег, суммы, количество чеков, статус.
- **Чеки** — все расходы со ссылками на файлы и пометкой «нет чека».

В выгрузку попадают смены «на проверке» и «принятые» (статус видно в колонке).

## Запуск

1. Создать бота у [@BotFather](https://t.me/BotFather), получить токен.
2. Узнать свой Telegram ID (например, у @userinfobot).
3. `cp .env.example .env` и заполнить `BOT_TOKEN`, `ADMIN_IDS`.
4. Запустить:

```bash
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
.venv/bin/python -m bot
```

или в Docker:

```bash
docker build -t cars_bot .
docker run -d --restart=always --env-file .env -v cars_bot_data:/data cars_bot
```

Данные — в SQLite (`DB_PATH`), бэкап = копия одного файла.

## Разработка

```bash
.venv/bin/pip install -r requirements-dev.txt
.venv/bin/python -m pytest
```

Структура: `bot/calc.py` — расчёт денег, `bot/export.py` — Excel/архив,
`bot/db.py` — база, `bot/handlers/` — сценарии (`driver`, `admin`, `common`).

## Ограничения первой версии

- Администраторы задаются списком в `ADMIN_IDS` и видят все проекты.
- Недописанный ввод (например, бот ждёт сумму) сбрасывается при перезапуске бота;
  сохранённые смены и чеки не теряются.
- Чеки хранятся на серверах Telegram (в базе — ссылки на файлы), скачиваются при выгрузке.
